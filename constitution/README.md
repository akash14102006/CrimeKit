# ENTERPRISE CONSTITUTION

Production-grade governance system for AI-first, full-stack engineering teams.

**Status:** Production  
**Version:** 1.0 (Refactored Enterprise Architecture)  
**Last Updated:** June 5, 2026

## 📚 STRUCTURE

The constitution is organized into 7 tiers:

| Tier | Purpose | Contents |
|------|---------|----------|
| **00_CORE** | Supreme governance | Universal principles, testing authority |
| **01_INTELLIGENCE** | Expertise & standards | Domain constitutions, skills, architectural patterns |
| **02_EXECUTION** | Workflows & policies | Processes, approval gates, decision workflows, AI agents |
| **03_GOVERNANCE** | Authority & compliance | Review boards, governance structures, compliance requirements |
| **04_KNOWLEDGE** | Reference library | Design patterns, templates, checklists, examples |
| **05_PROJECT_CONTEXT** | Business alignment | Product vision, architecture decisions, business goals |
| **06_WORKSPACE** | Working documents | Generated artifacts, analysis results, team outputs |
| **07_BOOTSTRAP** | Entry points | Quickstart guides, decision trees, navigation helpers |

## 🚀 QUICK START

### For New Projects
1. Start in [00_CORE](00_CORE) to understand **foundational principles**
2. Review [01_INTELLIGENCE](01_INTELLIGENCE)/CONSTITUTIONS for your **domain** (Frontend, Backend, Database, Testing, etc.)
3. Check [02_EXECUTION](02_EXECUTION)/WORKFLOWS for your **workflow** (feature development, deployment, etc.)
4. Verify [02_EXECUTION](02_EXECUTION)/POLICIES for **coding standards**
5. Check [03_GOVERNANCE](03_GOVERNANCE) to understand **who approves what**

→ See [07_BOOTSTRAP](07_BOOTSTRAP) for agent integration guides

→ See [03_GOVERNANCE](03_GOVERNANCE)/GOVERNANCE for review boards and authority
