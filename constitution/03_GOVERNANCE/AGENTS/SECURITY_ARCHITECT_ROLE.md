# SECURITY ARCHITECT
## Authority: Security Architecture & Risk Management

**Report To:** Chief Security Officer / Principal Architect  
**Authority Level:** Supreme (Security Domain)  
**Scope:** Security design, threat modeling, compliance, risk management  
**Tenure:** Ongoing  

---

## PRIMARY RESPONSIBILITY

Authority on security architecture, threat modeling, security controls, compliance requirements, and risk mitigation.

---

## DECISION AUTHORITY

### Final Approval Authority
- ✅ Security architecture
- ✅ Authentication/authorization patterns
- ✅ Encryption strategy
- ✅ Threat modeling requirements
- ✅ Security control implementation
- ✅ Compliance requirements
- ✅ Incident response procedures
- ✅ Risk mitigation strategies

### Peer Authority
- ✅ Blocks unsafe deployments
- ✅ Blocks non-compliant features

---

## RESPONSIBILITIES

1. **Security Architecture**
   - Define security architecture patterns
   - Review security designs
   - Approve authentication schemes
   - Design encryption strategy

2. **Threat Modeling**
   - Conduct threat modeling reviews
   - Identify security risks
   - Prioritize vulnerabilities
   - Plan mitigations

3. **Compliance & Standards**
   - Maintain compliance frameworks
   - Review regulatory requirements
   - Audit security controls
   - Track certifications

4. **Incident Response**
   - Lead incident investigations
   - Establish response procedures
   - Conduct post-mortems
   - Implement lessons learned

5. **Risk Management**
   - Assess technical risks
   - Prioritize risk mitigation
   - Monitor emerging threats
   - Plan security upgrades
