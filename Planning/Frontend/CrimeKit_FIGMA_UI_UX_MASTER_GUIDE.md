# FIGMA_UI_UX_MASTER_GUIDE

## Purpose

This document is the visual blueprint for designing every CrimeKit
screen in Figma.

------------------------------------------------------------------------

# 1. Design Philosophy

-   Enterprise SaaS
-   Government-grade trust
-   Investigator-first workflow
-   Minimal cognitive load
-   Clean information hierarchy

------------------------------------------------------------------------

# 2. Grid System

-   12-column desktop
-   8-column tablet
-   4-column mobile
-   8px spacing system
-   Max content width: 1600px

------------------------------------------------------------------------

# 3. Screen Structure

Top Navigation (64px)

Footer (optional)

# 4. Component Specifications

Buttons - Height: 40/48px - Radius: 12px

Inputs - Height: 44px - Label above field - Helper text below

Cards - Radius: 16px - Soft shadow - 24px padding

Tables - Sticky header - Row height: 48px - Search + Filters

Dialogs - Max width: 720px - Glass background
